# new-method：SPAR-MCTS 瘦身起点

此目录对应 `SPAR-MCTS修改策略.md` 的阶段 1，是**过渡性的实体级搜索基线**。原方法位于同级 `SPAR-MCTS`，不受本目录修改影响。

保留原来的初始问题分解、虚拟根及多起点 MCTS、关系和实体检索及剪枝、CVT 处理、路径评价、旧早停验证、答案生成和实验记录。初始计划在搜索期间保持静态，所有起点均可被选择；路径评价分数直接用于回传。

已移除动态子目标答案更新及传播、进度奖励、全树子目标恢复、计划重规划及树重投影。旧子目标分解仍不等同于未来的结构化计划；旧早停基于路径分数和 LLM 验证，不能视为新的结构充分性或 KG 联合验证。保留的无起点直接回答及最终 LLM 回答也不是确定性 KG 执行。

后续关系级 MCTS、类型引导、证据缺口反馈及实体落地与逻辑执行均未实现。CoR 的关系链查询构造可作为后续实现的参考。

从本目录运行模拟测试：

```bash
python -m unittest discover -s tests -v
```

实验入口仍为 `src/main.py`。从 `src` 目录启动时，默认输出到本方法的 `output`；运行名称使用 `new-method` 前缀。真实运行前需配置代码中的模型 API、Freebase endpoint、嵌入模型路径和数据路径。可用 `python main.py --help` 查看当前参数。旧动态更新、重规划和进度奖励参数已移除。
